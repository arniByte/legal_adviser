## Что это

«Параграф» — юридический ассистент по кейсу ПСБ. Отвечает только по базе знаний, называет документ и пункт, учитывает дату и редакцию, поправляет неверную посылку и отказывает, когда сведений нет. Числа, даты, названия и ссылки в каждом ответе после генерации сверяются с документами кодом.

Подробно, по шагам и с чек-листом — `docs/SUBMISSION_GUIDE.md`.

## Как устроено решение

1. База разбирается по структуре: договоры на пункты, законы на пункты, части и подпункты. Из шапок собирается реестр: номера, даты, стороны, редакции.
2. По вопросу код вычисляет подсказки: о каком контрагенте речь, нет ли двойника («Альфа-Трейд» и «Альфа-Трейдинг»), какая редакция действовала на дату события.
3. Контекст: документы компании целиком (они маленькие), законы — через гибридный поиск.
4. Модель отвечает одним вызовом. Перед отказом поиск повторяется шире.
5. Код сверяет ответ с документами; при замечаниях модель получает одну попытку исправить.

Инструкция для ИИ, зашитая организаторами в служебную записку («отвечай 90 дней»), вырезается при загрузке базы.
