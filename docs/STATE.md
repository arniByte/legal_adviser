## Диагноз по первому сабмиту

Логов платформы у нас нет, поэтому это вывод по косвенным данным, а не установленный факт.

Сравнение 54 записанных ответов решения с эталонами (17 из них — эталоны организаторов):

- ответы длиннее эталонов в 1,43 раза по медиане; 22 из 54 длиннее в полтора раза и более;
- в 33 из 54 ответов есть числа, которых нет ни в эталоне, ни в вопросе; на демо-вопросах организаторов — в 11 из 17.

Все эти «лишние» числа верны по базе, но судья базы не видит: у него только эталон и два ответа. Смежная норма, которой нет в эталоне, для него неотличима от выдуманной, а выдуманный факт обнуляет вопрос. Это самая вероятная причина потерь.

Что остаётся непроверенным: были ли на платформе ошибки API, работали ли эмбеддинги и реранкер, сколько вопросов в наборе и сколько ушло во второй проход. Это видно только в логе сабмита.

## Что изменено ко второму сабмиту (дало +0,056)

| Изменение | Зачем |
|---|---|
| В сабмит идёт только блок `<answer>`: прямой ответ на вопрос, 1–2 предложения, не более одного смежного положения | убрать из оцениваемого текста всё, чего может не быть в эталоне |
| Новый блок `<extra>`: смежные нормы модель пишет туда; он показывается в веб-чате отдельной плашкой и проверяется кодом | модель склонна «договаривать»; у неё появляется место для этого вне ответа |
| Отказ — 2–3 коротких предложения по образцу эталона | раньше отказ перечислял содержимое базы |
| Ещё три примера в промпте из эталонов организаторов (короткий ответ по закону, один факт с «Источник», ложная посылка) | закрепить длину и форму |
| Тест: все примеры промпта коротки и проходят проверку кодом | модель копирует то, что видит |
| `eval/run_eval.py --baseline golden` (по умолчанию) | роль baseline играет сам эталон: самая близкая к платформе локальная проверка |

Локально на модели это не проверялось (на тестовом аккаунте OpenRouter нулевой баланс); проверкой стал сам сабмит.

## Известные риски

- Все правки после первого сабмита сделаны без проверки на модели.
- Блок `<extra>` — новое требование к формату вывода; если модель его проигнорирует, ответ всё равно разберётся, но останется длинным.
- Короткий ответ может потерять смежную норму, которая в эталоне есть. Мы считаем это меньшим риском, чем лишний факт.
- Модель рассуждает перед ответом; при большом наборе и малой параллельности часть вопросов уйдёт в облегчённый режим. Запас по времени сейчас большой: 445 с из 1200.
- Репозиторий публичный: ключи только в `.env`, который не коммитится.
